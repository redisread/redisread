## 关于我

我是 Victor，GitHub 上的 **@redisread**。喜欢动手做东西，也喜欢探索技术如何让日常生活更方便。

我的项目围绕几个方向展开：**发现有趣的地方、阅读与信息订阅、个人知识管理**。从一个具体需求开始，把界面、服务和部署连接起来，逐步打磨成能用的作品。

- 🏔️ **探索与连接**：通过 GoMate 发现地点，找到一起出发的伙伴。
- 📚 **阅读与发现**：用每日一书、RSS 阅读器和产品故事，探索值得阅读的内容。
- 🗂️ **记录与整理**：尝试卡片盒笔记、双向链接和知识图谱，让信息产生连接。
- 🛠️ **持续实践**：在真实项目中探索 Web 开发、Cloudflare 和自动化工作流。
